**Source:** the mockup canvas "Brick OS UI mockups", version 16 (2026-11-09), https://claude.ai/artifact/Fa1bGq8ijVgG5UnrRhjh6b

**Rules for using this file**
- Every value is copied from the v2 boards. Nothing is invented.
- Where the boards say nothing, this file says **"ไม่ได้กำหนดใน mockup"** — ask or draw first, don't guess.
- px on the 1024×768 screen (boards are 1:1 with the device).

**Decisions from the user (grill, 2026-11-09)**
- Every screen looks like one OS: one status bar, one hint bar, one focus style, drawn by one shared code module.
- Big: body text 40, titles 56, rows 96, icons 64.
- Focus = white fill with black text (Google TV style); pictures get a white ring instead.
- Status bar: page title left; music, Bluetooth, mute, WiFi, time, battery right; each can be switched off in Settings.
- Hint bar: white button circles with black letters + a word.
- Home: a "เล่นต่อ" carousel on top + one row of 6 app icons.
- Games: console wheel → covers carousel, or a list with a big cover (SELECT switches, remembered per console).
- Console pictures: NX Redux's own console logos for now.
- Game count: real games only. No file sizes anywhere.
- Round 1: shared kit, Home, Games, Switcher, Settings. Round 2: YouTube, keyboard, in-game menu, music, video.

## 1. Rules for the real device

- The CPU draws the UI: solid surfaces, no blur, no shadows. Alpha only for rounded corners and the faded side items of a carousel / wheel.
- Fonts: Inter (Latin, digits) + IBM Plex Sans Thai (Thai), OFL. Line height 1.25.
- Icons: stroke line icons, stroke 2 on a 24 grid, one set (the SVG paths in `mockup_v2.py` `ICONS`).
- Animation: one tween, ease-out 180 ms, on pre-scaled images (scale covers/logos once when loaded, never per frame). Target ≥ 58 fps (NX_BENCH).
- Every token lives in one file, `res/bos/tokens.h` (C and C++). No hex colour or font size outside it.

| `bg` | `#000000` | Every screen |
| `surface` | `#1C1C1F` | App tiles, wheel cards |
| `surface2` | `#2C2C30` | Pills, the open category (selected, not focused), toggle track off, slider track |
| `text` | `#FFFFFF` | Main text, status bar |

| `focus` | `#F2F2F7` | Focused row/tile fill, picture ring, hint circles |
| `onfocus` | `#0B0B0D` | Text and icons on `focus` |
| `primary` | `#4A9BFF` | Toggle on; main action buttons. **Never the focus.** |
| `secondary` | `#8E8E93` | Neutral marks |
| `ok` | `#30D158` | Charging, the dot of the "เล่นต่อ" pill |
| `warn` | `#FFD60A` | Battery ≤ 20 % |
| `danger` | `#FF453A` | Battery ≤ 10 %, delete |
| `youtube` | `#FF0033` | YouTube watched bar only |

App icon colours (Home): เกม `#4A9BFF` · YouTube `#FF4D5E` · เพลง `#FF7AB6` · วิดีโอ `#FFB340` · Ports `#5EE0A0` · ตั้งค่า `#C7C7CC`.
Cover colours on the boards are placeholders for real art.

Why: white on black is 21:1 and `text2` ≥ 9:1, readable at an angle on the IPS panel. A white focus fill is the strongest
cue without a saturated colour (less tiring than blue); blue is kept for "on / go". Status always pairs colour with an icon
(the bolt when charging) so colour-blind users are covered.

## 4. Sizes and shape

| Element | Size | Radius |
|---|---|---|
| Status bar, hint bar | 64 high, padding 0 32 | — |
| List row | 96 high, padding 0 24 (20 in Settings categories), gap 20 | 20 |
| Row icon | 40 | — |
| App tile | 130×130, icon 64, gap 24, name below (gap 8) | 30 |
| Carousel centre cover | 346×260 | 24 |
| Carousel side / outer | 240×180 (opacity .55) / 180×135 (opacity .3), gap 24 | 20 / 18 |
| List-mode cover | 376×282 | 24 |
| Pill | 44 high, padding 0 18 | 22 |
| Toggle | 80×46, knob 38 | 23 |
| Slider | 240×12 | 6 |
| Hint circle | 40×40 | 20 |
| Hint pill (MENU …) | 40 high, padding 0 12 | 12 |

- **Focus** (made stronger 2026-11-10): fill `focus`, text/icon `onfocus`, weight 600.
  - Scale **1.12** for tiles, cards and quick-settings tiles. Full-width rows and sliders scale **1.04**, since they cannot grow more.
  - **Everything else that can be focused on the screen is drawn at 60 % alpha:** other tiles, rows, cards and buttons. Titles, captions, the status bar and the hint bar never dim.
  - Labels under tiles are `text` (white) at rest, so at 60 % they stay ≥ 7:1.
  - Cost: the dim is a per-texture alpha mod, and the focused tile is pre-rendered at 1.12. Nothing is drawn per frame.
- **Selected but not focused** (the open Settings category): fill `surface2`, text `text`, full alpha.
- **Dark only.** There is no light mode in UI 2.0 (decided 2026-11-10); it may come later. ธีมสี › พื้นหลัง still offers ดำ / เทาเข้ม.
- **Picture focus:** ring 4 px `focus`, offset 4. Pictures never get the white fill.

## 5. Shared pieces

### 5.1 Status bar (every screen, incl. in-game menu and YouTube in round 2)
- Left: the app's name (หน้าแรก, เกม, สลับเกม, ตั้งค่า), 30/600. The page's own subject goes in the large title (§5.5).
- Right, gap 22, in this order; an icon shows **only while its state is true**:
  1. ♪ music playing in the background
  2. Bluetooth — a device connected
  3. Mute — volume 0
  4. WiFi — WiFi on (strength bars) — 32 px icons
  5. Time 30/600
  6. Battery: "76%" 30/600, then the battery 46×24 (3 px border, radius 7, 3 px padding, fill = level, 4×8 tip).
- Battery colour: `text`; ≤ 20 % `warn`; ≤ 10 % `danger`; charging `ok` with a bolt (26) before the number.
- **ตั้งค่า › หน้าตา › แถบสถานะ:**
  - First a live preview of the bar.
  - Then one toggle each: เพลงที่เล่นอยู่, Bluetooth, ปิดเสียง, WiFi, เวลา, ตัวเลข % แบต. The battery icon always shows.
  - All on by default. One shared config that every app reads.
  - Stored as `statusbar=<bits>` in the shared settings file (music 1, BT 2, mute 4, WiFi 8, clock 16, % 32; default 63). The clock follows ระบบ › เวลาแบบ 24 ชั่วโมง.

### 5.2 Hint bar (every screen)
- Right group: at most 4 of A B X Y, gap 36, **A at the far right**, then B, X, Y to its left.
- Left slot: at most one system button (MENU, SELECT, START, L1/R1 …).
- A hint = cap + gap 12 + label 30 `text2`.
  - The cap is a circle 40 with the letter, or a pill for word buttons.
  - Cap colour = ธีมสี › สีปุ่มแถบล่าง (default `focus`, letter `onfocus`).
- No border line, no note text.

### 5.3 Carousel (Home "เล่นต่อ", Games cover mode, Switcher)
- Five slots on one centre line: outer, side, **centre**, side, outer. Sides and outer slots are cut by the screen edge.
- Sizes:

  | Where | Centre | Sides | Gap |
  |---|---|---|---|
  | **Home** | 346×260 | 240×180, op .55 | 24 |
  | **Full screen** (Games, Switcher) | 500×375 | 300×225, op .5 | 28 |

  Outer slots are the side size × .75, op .25.
- The centre has the ring while the carousel has focus. Without focus it keeps its size and loses the ring.
- Caption under the centre (padding-top 14, gap 4, centred): name 40/600, then meta 30 `text2` + a pill.
- 1 item: only the centre. 2 items: centre + one side.
- Missing cover: a `surface` card with the name 30/600 centred.

### 5.4 Pills
- `เล่นต่อ`: `surface2`, a 12 px `ok` dot, 26/600 — the game has a resume state.
- `กำลังเล่น`: `surface2`, 26/600 — Switcher, the game that opened it.
- `ใหม่`: `primary` with white 22/700 — an app installed since the user last opened แอปทั้งหมด.

### 5.5 Large title (iOS)
- Sits under the status bar, padding 4 40 12.
- The subject 56/700 (letter-spacing −0.5), and **right under it** its count or detail 30 `text2`.
- Used on:
  - Games wheel: console + "<N> เกม"
  - Cover and list mode: console + "<N> เกม · เรียง A–Z"
  - Switcher, แอปทั้งหมด
  - Every Settings page below the root

### 5.6 iOS group (Settings, and any list of options)
- **Card:** `surface`, radius 24, inset 40 from the screen edges; groups 16 apart.
  - Optional header above: 26/600 `text2`, padding 14 28 8.
  - Optional footer below: 26 `textoff`.
- **Row 96:**
  - Optional squircle icon 56: radius 26 %, a white 36 px glyph on the category colour.
  - Label 40/500.
  - Then one of: value 30 `text2` + chevron 28 `textoff`, a toggle, or key caps (§6.9).
- **Separators:** 1 px `#38383A`, from the label's left edge to the card's right edge. None under the last row or around the focused row.
- **Focused row:**
  - `focus` fill, radius 20, scale 1.04; the other rows at 60 % (§4).
  - Label 600 `onfocus`, value `#3A3A3C`.
  - The squircle keeps its colour.
- **Long lists** scroll so the focused row stays 1 row from the edge. A 6 px `textoff` scroll bar sits at the right.

### 5.7 Motion
- Every animation is ease-out and moves **pictures already drawn**.
- The leaving screen and the coming screen are each rendered once to a texture. After that, only their positions and alpha change per frame.
- No blur, no shadows. Target ≥ 58 fps, measured with NX_BENCH.

| What | How | Time |
|---|---|---|
| Push a page / back | The new page slides in from the right. The old one moves left 30 % and darkens to 35 %. Back plays it reversed. | 240 ms |
| Open an app or game | The focused tile scales up to full screen, then fades to black. The app starts. | 260 ms |
| Back to Home | Fade in from black | 200 ms |
| Focus, carousel, wheel | The highlight or slots tween to their new place | 120–180 ms |
| Sheet / pop-up | Slides up from the bottom; the page behind dims to 60 % black | 220 ms |
| Toggle | The knob slides; the track colour cross-fades | 150 ms |

- **ตั้งค่า › หน้าตา › ภาพเคลื่อนไหว:** เต็ม (default) / น้อย (fades only, 120 ms) / ปิด.
- This replaces v1's "Show menu animations" and "Show menu transitions".

### 5.8 Growth rules (anything the user adds must fit without a redesign)
- **Apps:** every `Tools/*.pak`, shipped or installed (e.g. PortMaster), appears in แอปทั้งหมด by itself. An app with no icon gets the generic `box` icon in `secondary`.
- **Consoles:** a console with at least one game appears in the wheel by itself. The wheel wraps.
- **Names:** one line, cut with "…". If the focused name is cut, it scrolls slowly after 1 s.
- **Counts:** real games only (§6.2).
- **Pictures:** each picture has a fallback chain (§6.2, §5.3), so nothing is ever blank.

## 6. Screens (round 1)

### 6.1 Home ("หน้าแรก")
1. Status bar "หน้าแรก".
2. Section label "เล่นต่อ" 30/600 `text2`, padding 8 40 10.
3. Carousel (Home size) of Recents.
   - Caption: name, then "<console> · <when played>".
   - A `เล่นต่อ` pill when the game has a resume state.
4. App row (padding-top 14, gap 12, centred): the **pinned** apps, then **ทั้งหมด** (grid icon) last.
   - Tile 112 (radius 26), icon 64, name 30 under it (box 128).
   - Focused tile: white with a black icon, name `text` 600.
   - Other tiles: `surface`, coloured icon, name `text2`.
   - Default pins: เกม, YouTube, เพลง, วิดีโอ, Ports, ตั้งค่า.
   - Fewer pins: the row stays centred. More than 6 pins: the row scrolls left/right with the focus, and ทั้งหมด is always last.
5. Hint bar: carousel: left **MENU** ตัวเลือก (§6.10); right **A** เล่นต่อ · **X** ปิด (closes the game: it leaves เล่นต่อ and สลับเกม; its save stays, as §6.5) · **Y** ค้นหา. App row: **A** เปิด · **X** จัดเรียง · **Y** ค้นหา.
- **System keys, unchanged from v1** (checked in `keymon.c` / `home.c` 2026-11-10):
  - MENU tap on a game = ตัวเลือกเกม (§6.10). MENU held = สลับเกม (§6.5), on every screen.
  - HOME key (Brick Pro) = TrimUI's own quick panel (the stock OSD: brightness, volume, WiFi, BT …). It draws over any app, games included, so Brick OS keeps it and does **not** add its own quick-settings panel. Round 2 re-skins its PNG assets (`bg.png` …) to the theme.
- Up/Down moves between the carousel and the app row.
- **จัดเรียง (reorder, board v2-HomeReorder):** X on a pinned app picks it up.
  - The picked app is drawn focused, lifted 12 px, with a 40 px `<` `>` on each side. Nothing else changes: no wobble, no shadow.
  - Left/Right swaps it with its neighbour; the neighbours slide with the normal 120 ms focus tween.
  - The carousel dims to 35 %. ทั้งหมด is hidden while reordering, since it never moves.
  - Hint bar: left **◀ ▶** ย้าย; right **A** เสร็จ (saves the order) · **B** ยกเลิก (restores it).
  - The same order is used by แอปทั้งหมด.
- Icons: the YouTube tile is a rounded screen outline with a filled ▶, all in the tile's colour (red at rest, `onfocus` when focused). It has no white.
- **No games to continue:** the centre box stays (346×260 `surface`) with "ว่าง" 56/600 `textoff` in its middle; the caption keeps its space empty, so the app row never moves. Focus starts on the app row.
- **Layout rule (all screens):** a line that may be empty still keeps its height, so nothing below it moves when the content changes.

### 6.6 ตั้งค่า — layout: iPad two columns (chosen 2026-11-09; board v2-SettingsIPad)
- Status bar "ตั้งค่า".

- **Value rows (user feedback 2026-11-10):**
  - A row changed with Left/Right shows `‹ value ›` (chevl / chev 28, `#3A3A3C` on the white focus) while focused, so it reads as adjustable.
  - **A** on such a row opens its **value list**: a §5.7 sheet (600 wide, 60 % black behind), title 44/700, rows 84, up to 6 then it scrolls (L1/R1 a page). The current value has a `check` in `primary`. **A** เลือก · **B** ยกเลิก.

- **No cut names:** when a name and its value don't fit on one line, the value moves under the name (name at 32 % of the row, value at 73 %, both left-aligned). A slider there shortens to the room left. Only a name longer than the whole row is still cut with "…".
  - **One layout per row (user feedback 2026-11-11):** whether a row takes one line or two is decided from its widest choice, the focused weight (600) and the `‹ ›`, never from the value shown now. The row never jumps between one and two lines when its value changes or it gains focus.
- **Connected mark:** the connected WiFi network has a check (`check` 34, 10 px after the name; `primary` in a dimmed row, the focus text colour in a focused row). Its description reads "เชื่อมต่อแล้ว · IP x.x.x.x".
- Thai at 600/700 uses a real SemiBold (`res/font1-thai-semibold.ttf`, from IBM Plex Sans Thai SemiBold via `scripts/font/gen_thai_font.py`), never SDL_ttf's synthetic bold, which blurs and clips Thai.
- The status bar is drawn after the columns, so a scrolled category never shows through it.
- A row's description (26 `textoff` under the group) wraps to two lines (`BOS_textWrap`: at spaces, else between Thai clusters, never before a vowel or tone mark); only a third line is cut with "…".
- **Long text (all screens, user request 2026-11-10):** focused text that still doesn't fit scrolls instead of ending in "…" (`BOS_textMarquee`: hold 0.5 s, 120 px/s, hold 1 s, back (user, 2026-11-10)). It covers the focused row's name and value, the focused category, the value list's focused row, a description's last line, and the game names under Home's / เกม's / สลับเกม's covers and in เกม's list. Unfocused rows keep "…".
